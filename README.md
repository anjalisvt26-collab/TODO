# TOdo-game
Todo Game is a simple task management application built using HTML, CSS, and JavaScript. It allows users to add new tasks and delete tasks when they are no longer needed. The project features a clean and easy-to-use interface, making it a great beginner project for learning JavaScript and DOM manipulation.


Features
 Add new tasks instantly.
 Delete tasks with a single click.
 Clean and user-friendly interface.
 Fast and responsive performance.
 Works smoothly on desktop and mobile devices.

 Technologies Used
HTML – Creates the structure of the application.
CSS – Styles the user interface and makes it visually appealing.
JavaScript – Handles the functionality, such as adding and deleting tasks.


How It Works
Enter a task in the input field.
Click the Add button to add the task to the list.
The task will appear in the todo list.
Click the Delete button next to a task to remove it from the list.
Repeat the process to manage your tasks easily.
